# تحليل صور الأكل داخل الشات

هذا التحديث مبني على `gym-dashboard (2).zip`. انسخ ملفات ZIP إلى جذر Laravel مع الحفاظ على مساراتها، ثم شغّل:

```powershell
php artisan optimize:clear
```

حدّث الصفحة على الهاتف. لا توجد migrations أو حزم إضافية أو ضرورة لتشغيل npm build لهذا التحديث؛ الواجهة داخل Blade.

## الاستخدام

- افتح الشات واضغط 📷 ثم اختر صورة الوجبة من الهاتف أو الكاميرا إذا عرضها متصفحك.
- راجع المعاينة. يمكنك إزالة الصورة قبل الإرسال، وإضافة وصف اختياري مثل «150 جم رز مطبوخ و200 جم فراخ مشوية بدون زيت».
- اضغط إرسال حتى بدون نص. يقدّر Gemini الأصناف والكميات والسعرات والبروتين والكربوهيدرات والدهون وإجمالي الوجبة. الصورة وحدها لا تثبت الوزن أو كمية الزيت، فالنتيجة تقريبية.
- لتعديل التقدير أرفق الصورة من جديد مع الكمية الصحيحة. الصور ونتائجها لا تدخل سجل السياق النصي اللاحق.
- لا يتم حفظ وجبة أو تعديل سجل التغذية تلقائيًا. منطق التمارين وحسابات التغذية الحالية لم يتغير.

## الإعدادات

يستخدم نفس إعدادات Gemini الموجودة في المشروع، دون إعداد جديد:

```dotenv
GEMINI_API_KEY=your-key-here
GEMINI_MODEL=your-image-capable-model
GEMINI_FALLBACK_MODEL=your-image-capable-fallback-model
```

هذه قيم توضيحية فقط؛ احتفظ بمفتاحك الفعلي في `.env` عندك ولا تنشره. يلزم أن يدعم الموديل الصور وأن يكون متاحًا لمفتاحك وحصتك. لا يضمن التحديث حصة مجانية أو إلغاء رسوم مزود Gemini. المفتاح لا يصل للمتصفح.

الحد: صورة واحدة JPG أو PNG أو WebP، حتى 5 MiB، وأبعاد لا تتجاوز 10000×10000. يتم فحص المحتوى على الخادم؛ SVG والملفات المزيفة مرفوضة. HEIC غير مدعوم؛ احفظه JPG قبل الرفع.

إذا رفض PHP رفع صورة كبيرة، اضبط إعدادات PHP المستخدم بواسطة السيرفر ثم أعد تشغيله:

```ini
upload_max_filesize = 6M
post_max_size = 8M
```

لو لديك Nginx/Proxy راجع حد حجم الطلب لديه أيضًا. الإرسال يستعمل route الشات الحالي بنفس تسجيل الدخول وCSRF وحد الطلبات الموجود. يتم إرسال الصورة ووصفها فقط إلى Google Gemini، دون اسم الحساب أو بياناته أو سجل المحادثة. لا تُحفظ الصورة في public/storage أو قاعدة البيانات؛ يستخدم Laravel ملف الرفع المؤقت، والمعاينة تظل في ذاكرة الصفحة حتى بدء محادثة جديدة أو إغلاقها. تنطبق سياسات مزود Gemini على البيانات المرسلة إليه.

يُرسل المحتوى إلى `generateContent` باستخدام `inlineData`، وفق [مرجع Gemini الرسمي](https://ai.google.dev/api/generate-content). لا يسجل المسار الجديد الصور أو وصفها أو المفاتيح أو نص أخطاء المزود. لا يوجد إرسال تجريبي حقيقي ضمن الاختبارات؛ تُستخدم استجابات وهمية.

## الاختبارات

```powershell
php artisan test --filter=ChatbotFoodPhotoTest
php artisan test --filter=ChatbotResponseTest
node --test tests/Frontend/chatbot-food-photo.test.cjs
```

اختبارات الخادم تتحقق من إرسال البيانات الثنائية والوصف، وعدم تسريب الحساب والسياق، وعدم حفظ وجبات، ورفض الملفات غير المناسبة، وحماية تسجيل الدخول، والمفتاح المفقود، وfallback وحد الاستخدام وأخطاء الاتصال. اختبارات JavaScript تتحقق من الاختيار والإزالة وتنظيف المعاينات وmultipart واستمرار النص وعرض الأخطاء وتهريب HTML.

لا يتضمن ZIP ملف `.env` أو أسرار أو vendor أو node_modules أو ملفات cache.
