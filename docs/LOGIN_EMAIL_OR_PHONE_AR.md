# تسجيل الدخول بالإيميل أو رقم الهاتف

انسخ ملفات ZIP إلى جذر المشروع بنفس المسارات ثم شغّل:

```powershell
php artisan optimize:clear
```

حدّث صفحة تسجيل الدخول. لا توجد migrations أو حزم جديدة أو تعديلات `.env`، ولا يلزم npm build. تبويبات واتساب وQueue وScheduler لا تحتاج تعديلًا بسبب هذا التحديث.

الخانة أصبحت «البريد الإلكتروني أو رقم الهاتف». استخدم أيًا منهما مع نفس كلمة المرور الحالية. تذكرني، وإظهار كلمة المرور، وتوجيه السوبر أدمن والمشترك، ومنع الحساب المعطل، وتجديد الجلسة كلها محفوظة. حقل الدخول ما زال اسمه `email` داخليًا للحفاظ على توافق النماذج والعملاء ورسائل الأخطاء الحالية، لكن نوعه Text لقبول الهاتف.

أمثلة متكافئة لنفس الرقم المصري:

- `01012345678`
- `+201012345678`
- `00201012345678`
- `201012345678`
- `010 1234 5678`
- `٠١٠١٢٣٤٥٦٧٨`

تُدعم المسافات والأقواس والنقاط والشرطات والأرقام العربية والفارسية في المدخل وفي أرقام الحسابات القديمة، دون تغيير الرقم المخزن. الأرقام الدولية الأخرى تستخدم `+` أو `00` مع كود الدولة. دعم الرقم المصري في تسجيل الدخول مستقل عن إعداد تطبيع أرقام تذكيرات واتساب؛ لا تتغير إعدادات الإرسال بهذا التحديث.

لو كان نفس الرقم مسجلًا لحسابين بصيغ متكافئة، يرفض تسجيل الدخول بهذا الرقم حتى تُصحح البيانات، ويظل الدخول بالإيميل متاحًا. لا يختار النظام حسابًا اعتمادًا على كلمة المرور بين حسابات تشترك في الرقم. رسالة الفشل واحدة للرقم غير الموجود أو المتكرر أو كلمة المرور الخاطئة.

يبقى قفل محاولات الدخول بعد 5 محاولات فاشلة خلال دقيقة لكل هوية موحدة وعنوان IP، ولا يتيح تغيير صيغة الرقم المصري أو حالة أحرف الإيميل تجاوز القفل. تُستخدم استعلامات ذات معاملات مربوطة لقيم المستخدم. البحث يدعم أرقام الحسابات القديمة كما كُتبت باستخدام REPLACE؛ لا يضيف عمودًا جديدًا أو يعيد كتابة الأرقام. عند وجود أعداد كبيرة جدًا من الحسابات قد يلزم لاحقًا عمود رقم موحد مفهرس لتسريع هذا البحث.

للتجربة: ادخل بإيميلك، اخرج، ثم ادخل برقم حسابك ونفس كلمة المرور. جرّب الصيغة المحلية و`+20`. جرّب كلمة مرور خاطئة وتأكد أن الدخول يرفضها. لا يلزم إرسال رسالة واتساب أو تشغيل البروفايدر لإتمام تسجيل الدخول بكلمة المرور.

الواجهة تحتفظ بالوضع الفاتح والداكن، وتستخدم خطًا 16px وارتفاعًا مناسبًا للمس في حقول الدخول، مع دعم الملء التلقائي لاسم المستخدم وكلمة المرور.

```powershell
php artisan test --filter=EmailOrPhoneLoginTest
php artisan test --filter=AuthenticationTest
```

الاختبارات تشمل صيغ الهاتف وتنسيق الأرقام القديمة والأرقام الدولية، والإيميل وحالة الأحرف، والحساب المعطل، والتكرار الملتبس، وكلمة المرور الخاطئة، والحد من المحاولات، وتذكرني، وتوجيه السوبر أدمن، وصحة نموذج الدخول. لا يتضمن ZIP `.env` أو أسرارًا أو vendor أو node_modules، ولا يغير منطق التمارين أو التغذية أو واتساب.
