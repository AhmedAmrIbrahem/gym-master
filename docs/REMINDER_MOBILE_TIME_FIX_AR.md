# إصلاح قص حقل الوقت على الهاتف

كان حقل الوقت داخل عمود ثابت 135px على الهاتف، وقاعدة CSS أعلى أولوية جعلت خطه 21px بدل الحجم المقصود، فظهرت AM/PM مقصوصة.

أصبح اسم اليوم والتفعيل في الصف العلوي، وحقل الوقت بعرض الصف أسفله على الشاشات حتى 560px. حُدد خط الإدخال بـ16px وارتفاعه 48px، وأزيل الحد الأدنى الضمني لعرض fieldset لمنع تمدد الحقول خارج البطاقة. على الكمبيوتر يبقى اليوم والموعد بجانب بعضهما مع عرض أوسع للوقت.

الملف المعدل الوحيد:

- `resources/views/profile/partials/gym-reminder.blade.php`

ويتضمن ZIP هذا الدليل الجديد: `docs/REMINDER_MOBILE_TIME_FIX_AR.md`.

فك الملفات فوق جذر المشروع الحالي، ثم نفّذ:

```powershell
php artisan view:clear
```

حدّث الصفحة بـCtrl+F5 أو أعد تحميلها على الهاتف. لا تحتاج تغيير .env أو إعادة تشغيل الطابور أو البروفايدر أو تشغيل migration أو npm. التنسيقات داخل Blade، ولم تتغير أسماء حقول الأيام أو طريقة حفظ الوقت أو منطق الإرسال أو صلاحيات الأدمن.

تم التحقق باختبارات عرض وحفظ الملف الشخصي والجدول الأسبوعي الحالية. لم تتوفر بيئة Safari فعلية للفحص الآلي؛ تحقق على الهاتف من ظهور الوقت كاملًا وإمكانية فتح منتقي الساعة.
