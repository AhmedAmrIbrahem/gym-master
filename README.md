# 🏋️‍♂️ Gym Master

**Gym Master** هو تطبيق ويب متكامل لإدارة الجيم ومتابعة اللياقة البدنية مبني بإطار لاراڤيل (Laravel). يساعد المستخدمين على إدارة التمارين، متابعة التغذية والماكروز اليومية، تسجيل قياسات الجسم، والتفاعل مع كوتش ذكي لمساعدتهم في رحلتهم الرياضية.

---

## ✨ المميزات الرئيسية

- **🧮 حاسبة السعرات والماكروز الذكية:** تقدير معدل الأيض الأساسي (BMR)، السعرات للثبات (TDEE)، وأهداف الماكروز اليومية (بروتين، كارب، دهون) بناءً على بيانات الجسم والأهداف.
- **📊 تتبع قياسات الجسم:** تسجيل ومتابعة الوزن، الطول، ومقاسات الجسم بمرور الوقت.
- **💪 برامج التمارين وسجلات الجلسات:** إنشاء وإدارة جدول التمارين، تسجيل الجلسات اليومية، ومتابعة الأداء.
- **🥗 متابعة الوجبات والتغذية:** تسجيل الأطعمة اليومية ومقارنتها بالأهداف المحددة سواء في أيام الجيم أو الراحة.
- **🤖 المساعد الذكي (Chatbot):** مساعد ذكي للإجابة على الأسئلة الخاصة بالتمارين والتغذية وبيانات المشترك.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Backend:** PHP 8.2+, Laravel Framework
- **Database:** MySQL
- **Frontend:** Blade, Tailwind CSS
